## Install

Pick one of the following:

- **ComfyUI-Manager**: Manager → "Install via Git URL", paste `https://github.com/Xeitoops/ComfyUI-NodeTools`
- **git**: in `ComfyUI/custom_nodes/`, run

  ```
  git clone https://github.com/Xeitoops/ComfyUI-NodeTools
  ```

- **Manual**: download the ZIP from GitHub (Code → Download ZIP), unzip it and put the folder into `ComfyUI/custom_nodes/`

Then restart ComfyUI and reload the browser tab (Ctrl+F5 for a hard reload).

> The Comfy Registry versions are currently held for manual review, so installing by name in ComfyUI-Manager may not work yet. Use one of the methods above.

## Requirements

Developed and tested on ComfyUI 0.43.0 with frontend 1.57.4. Other versions untested.
